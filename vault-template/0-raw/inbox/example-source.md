# Example source

This file is here so the ledger row above points at something real.

Sources are **immutable**. Once captured, a file in `0-raw/` is never edited —
not to fix a typo, not to improve it. It is the record of what you actually
saw. Everything you conclude from it goes in `1-wiki/`, citing this path.

If you disagree with it later, you do not change it. You write a page that
disagrees, and cite both.
