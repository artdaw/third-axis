# Confidence

`high` · `medium` · `low` · `contested`

This page is deliberately marked `low`, and it is telling the truth: it is
built from one passing reference that does not really explain its subject.

**Never raise a stated confidence past what the source supports.** Rounding a
thin page up to `medium` so it looks finished is the most common way a
knowledge base starts lying to the person who built it.

`low` is a valid, permanent, honest outcome.
